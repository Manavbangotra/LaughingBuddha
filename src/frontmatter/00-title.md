# Machines That Learn and Act

**A Complete Textbook of Modern AI — from Mathematical Foundations to Production Agentic Systems**

*First Edition*

---

## About this book

This is a technical textbook, not an overview. It is written for a reader who
intends to understand modern artificial intelligence well enough to build
production systems with it, read the research literature without a translator,
and eventually contribute to that literature.

It begins with the mathematics that AI actually uses and ends with the frontier
of current research. In between it treats classical machine learning, deep
learning, the Transformer architecture, language models, retrieval, multimodal
systems, agents, tool protocols, serving infrastructure, evaluation, and
security — each as a subject with internal mechanics worth understanding, not as
a product category to be summarised.

The book assumes basic programming experience and a willingness to work through
mathematics. It assumes nothing else.

## Conventions

Chapters follow a fixed structure so the book can be read linearly or used as a
reference. Every technical term is defined once and used consistently
thereafter; the complete glossary and the notation table are generated from the
same data the chapters draw on, so they cannot drift apart.

Code is tagged by verification tier. Listings marked as executed were run
against the versions recorded in the repository. Listings that require a GPU,
network access, or model weights too large to run locally are marked as such and
were verified by static analysis and review rather than execution — the book
says which, rather than implying everything was run.

Technologies are labelled by maturity — **ESTABLISHED**, **MATURE**,
**EMERGING**, **EXPERIMENTAL**, or **RESEARCH FRONTIER**. Experimental results
are not presented as settled fact, and no citation appears without having been
checked against a primary source.
